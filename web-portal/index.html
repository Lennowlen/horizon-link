Panduan Setup MicroSD (Plug & Play)

Dua langkah mudah untuk menghubungkan konsol Switch CFW Anda ke HorizonLink

1

Ekstrak Paket SD Card

Unduh file HorizonLink-Switch-SDCard.zip dari rilis terbaru. Ekstrak langsung ke direktori paling luar (root) microSD Anda. File hosts emummc.txt dan homebrew HorizonLink.nro otomatis terpasang rapi.

2

Tautkan Akun via Homebrew

Nyalakan Switch, buka Homebrew Menu (Album), jalankan HorizonLink. Masukkan email & password akun yang telah Anda daftarkan di portal ini. Selesai! Buka game favorit dan mulai mabar.
